# 楚汉烽烟 · 中国象棋肉鸽闯关

一款以中国象棋为底子的 Roguelike 闯关网页游戏。开局规则与象棋**完全一致**,此后每一步都在与"永久死亡"博弈。

## 玩法特色

- **开局双选**: 开局即获两次「三选一」招募奇兵;每击败一关敌人,再获一次三选一(棋子或军需)。
- **永久阵亡**: 阵亡棋子不会复活(「还魂丹」随机救回一名,事件中也可指定复活)。
- **主帅标识**: 敌方主帅(将/蚩尤)头顶金色「将/王」标,击倒即胜;每关敌军必有主帅(裁剪不会再误删将)。点击任意敌军棋子即可查看其行动范围、吃子对象与技能(只读)。
- **移动端适配**: 全部操作支持触屏(点按走子/技能/查看敌军,「取消选择」代替右键),小屏自动缩放滚动。
- **100+ 棋子**: 7 个标准棋子 + 99 个特色棋子(其中凡品 26 个): 天马、神炮、朱雀、青龙、悟空、吕布、诸葛亮……各有不同的行动轨迹、部署区域、主动技能与被动光环(治疗、眩晕、中毒、自爆、反震、召唤、再动、空城计等)。
- **气力系统**: 每回合「走一步 + 放一次主动技能」,技能消耗气力与冷却。
- **军需强化**(已拆分,不再有全体加血/加伤的过于超模 buff): 虎骨膏/淬锋石为**一名**棋子生命上限/伤害+1(每子至多+3);祈福签选 **3 名**棋子,各 50% 概率成功升级(失败无变化);另有还魂丹、锦囊妙计、真龙龙袍。
- **行军奇遇**: **每两次战斗结束后**触发一次随机事件(57 种,整局不重复)。每个事件有完整的故事介绍与多个选项,须权衡利弊: 概率强化、突发战斗(胜利有稀有度提升的特殊奖励)、献祭换将、替换棋子(蜕变为同/更高稀有度)、指定复活、敌军下战增强/削弱等。
- **敌军成长**: 敌军数量与你的部署挂钩,伤害、精英比例、技能频率随胜场攀升。
- **12 关战役**: 第4关小Boss「吕布」、第8关小Boss「曹操」、第12关三阶段最终Boss「蚩尤」(魔威→狂怒,每阶段更强)。
- **存档/继续(单栏位)**: 每次进入部署自动存档;战斗中点「保存退出」可回主菜单,主菜单「继续征战」接着打。战败或通关后存档清除。结算弹窗不可点外关闭(避免卡死)。

## 运行方式

直接双击打开 `index.html` 即可游玩;或在项目目录启动静态服务器:

```bash
python3 -m http.server 8123
# 浏览器访问 http://127.0.0.1:8123
```

## 自动化测试

```bash
node tests/test.js      # 规则单测 + 新内容单测 + 整局模拟(含Boss阶段验证)
node tests/ui_test.js   # DOM冒烟测试(需 npm install --no-save jsdom)
```

## 目录结构

```
index.html            入口
css/style.css         主题样式
js/data/pieces.js     7个标准棋子 + 99个特色棋子/召唤物/Boss 数据
js/data/battles.js    12关战役、敌方军队生成与难度缩放、稀有度权重
js/data/events.js     57个行军奇遇事件(每2战触发一次)
js/core/engine.js     象棋规则引擎(移动/将军/伤害/状态/光环)
js/core/skills.js     主动技能系统(21种技能)
js/core/ai.js         敌方AI(走子评估+技能使用)
js/core/run.js        肉鸽流程(招募/部署/奖励/事件/突发战斗/存档)
js/ui/ui.js           界面渲染与交互(事件、选子、结算、存档UI)
js/main.js            启动引导
tests/                自动化测试
```

## 操作说明

- 点击己方棋子 → 显示可走位置(绿点=移动,红圈=吃子,橙圈=远程射击/技能目标)
- 点击任意**敌军棋子** → 同样显示其行动范围/吃子对象与技能(只读,不可操作);点棋盘空白处关闭
- 每回合**至多走一步 + 用一次主动技能**(走完必须点「结束回合」,不可无限行动;吃子「再动」类被动有次数限制)
- 选中后右侧出现「技能」按钮,点技能再点目标即可释放
- 每关开战前自由布阵,各棋子有部署区域限制(部署越多,敌军也越多)
- 事件弹窗中点击选项生效;需要选子时点击棋子头像再点「确定」
- 右侧可查看敌情、我方名册、战报;点「图鉴」查看全部棋子
- 战斗中可点右上角「保存退出」,主菜单「继续征战」接着打
